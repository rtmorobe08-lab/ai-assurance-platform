Discovery & Audit Checklist (Pillar 1 Specification)

This operational checklist governs the identification and cataloging of all artificial intelligence systems deployed across SMME environments:

  • Shadow AI Inventory: Identify all unauthorized browser extensions, external cloud LLM accounts, and API keys utilized by staff.
  • Data Flow Mapping: Trace customer PII, financial records, and operational telemetry from input ingestion nodes to third-party model context windows.
  • Exposure Scoring: Assign risk weighting based on confidentiality level and statutory jurisdiction (POPIA compliance boundaries).

Human-in-the-Loop (HITL) Control Matrix (Pillar 2 Specification)

Mandatory decision checkpoints preventing autonomous agent execution errors in critical operations:

  • Financial Thresholds: Any automated invoice processing or transaction refund exceeding R1,000 requires explicit secondary human sign-off.
  • External Communications: Automated customer emails or legal notices generated by agents must pass a staged review queue.
  • Access Governance: RBAC enforcement restricting autonomous write-access to primary database repositories.

Vendor Diligence & SaaS Vetting Guide (Pillar 3 Specification)

Standardized evaluation criteria for external AI model vendors and cloud hosting sub-processors:

  • Zero Data Retention: Verification that vendor APIs do not store, log, or train on proprietary client inputs.
  • Cross-Border Compliance: Ensuring cloud storage encryption and regional server hosting comply with domestic privacy statutes.
  • SLA Verification: Minimum uptime and security patch response times mandated for third-party partners.

Continuous Red-Teaming & Testing Protocols (Pillar 4 Specification)

Ongoing verification procedures maintaining long-term system integrity:

  • Adversarial Prompt Checks: Quarterly injection and jailbreak resistance testing against custom model deployments.
  • Hallucination Tracking: Logging output discrepancies and grounding failures in retrieval-augmented generation pipelines.
  • Audit Log Archival: Immutable record keeping for quarterly enterprise supply chain compliance reviews.
